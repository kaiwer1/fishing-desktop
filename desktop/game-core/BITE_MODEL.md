# 浮漂等待、漂相与提竿模型

2026-10-28。`FloatBiteSimulation.cs` 是本项目原创的单竿遇鱼模型，接在宿主确认的有效落水之后。它不是 RF4 服务端规则，也不是完整鱼群、河床、浮力或遛鱼实现。单独构造本模型不能证明抛投已付费，更不能授予鱼、修改背包或写存档。

## 输入与推进

- 宿主提供已确认 `sessionId`、`uint` 种子、四段明确的步数，以及当前候选池和每模拟秒危险率。构造者线程独占访问，页面不得直接调用模拟接口。
- 每步固定 50 毫秒；`Advance` 每次只接受 0 至 250 毫秒活动时间，保留不足一步的余数。零时间不推进。模型没有墙钟、计时器、自动追赶、存档或视图依赖。
- 调用者负责在菜单、失焦、竖屏、观赏或宿主暂停时停止提供活动时间；同一实例跨页面重载保留。重启不保存半截鱼口，仍由正式会话恢复流程收束。
- `SetEnvironment` 只改变后续搜索输入，不重置时间、阈值或累计暴露。环境明确不可用时结束本轮；缺配置、非法值和合法零鱼口是不同情况。

规则对象要求稳定、接近、试探、有效提竿四段各为 1 至 12000 步，首版不隐式跳过某段。具体生产参数由宿主明确提供，纯模型不内置新手保底或“65 秒自动咬钩”。

## 搜索与锁定目标

`settling → searching → approaching → nibbling → strikeable` 按活动步运行。进入搜索时将 `searchEpoch` 增加一次，以独立随机流取开区间 `u = (高32位 + 0.5) / 2^32`，目标危险量为 `-ln(1-u)`。每个合法搜索步累计 `hazardPerSecond × 0.05`；达到阈值才选择目标。

候选池至多 64 个不同物种键，权重为 0 至 1000000 的整数，按物种键排序后进行加权选择。空池或总权重为零保持等待、暴露与原阈值，不发鱼、不不断重抽；危险率为零同样合法。危险率必须有限且在 0 至 1000 范围内。参数完整但暂时无鱼时，可在之后更新环境继续同一轮搜索。

搜索、物种选择和体型使用三个独立的 SplitMix64 状态流，算法及整数溢出行为在源码中明确，不依赖 .NET `Random`。权重和质量范围采用拒绝抽样后的有界整数；质量是配置上下限之间的均匀整数毫克，范围限制为 1 至 10^12 毫克。该均匀体型分布仅为首版原创调参方式，不是生物统计结论。等待时间不参与体型计算。

目标在 `approaching` 开始时一次锁定。`encounterId` 由会话、搜索序号和固定域标识进行 SHA-256 派生，与鱼种/质量随机流分离。接近、试探、提竿、页面重建不得重新抽取鱼种或质量。后续环境取消该物种资格或明确失效时，当前目标进入 `retrieve-required`，保留身份用于核对，不替换另一条鱼。

`FloatBiteSnapshot.Target`、搜索阈值、累计量和提竿窗口端点属于宿主内部数据。面向玩家的投影须逐项取值，只暴露漂相、当前动作状态与必要的会话身份，不能序列化整个内部快照或提前显示鱼种/准确重量。

## 提竿与失饵

有效区间为 `[openStep, closeStep)`。进入 `strikeable` 当步可提竿；推进到 `closeStep` 时先处理过期，再接纳该步输入，因此边界当步不再有效。页面报告的过去时间不能改变宿主接纳步。

`Strike(sessionId, encounterId)` 必须匹配当前会话及当前遇鱼。尚无遇鱼时使用 `Guid.Empty`，遇鱼后空身份或旧身份直接拒绝，不能影响当前鱼口。

- 有效提竿进入 `hooked`，只返回一次 `ShouldStartFight = true`，保留同一目标。该模型到此停止推进；它不自动收线、不入护、不发钱或经验。
- 空提、过早提竿及错过鱼口，在本首版明确采用脱饵规则，进入 `retrieve-required`。这是已付费钩上鱼饵的运行时状态，不是再次扣一份背包鱼饵。
- 本首版脱饵后不继续搜索，不自动补饵，不退款；玩家须按正式会话流程收竿后再抛。未来保留鱼饵后重新搜索属于另一个配置版本，不默默启用。
- 重复成功提竿、过期动作、旧会话和旧遇鱼不再产生搏斗。没有“按住右键等待下次有效”的缓存。
- `End` 结束当前运行时；`retrieve-required`/`ended` 的 `TerminalEvent` 在本模型生命周期最多一次。该事件仍不代表持久化终结事务已写入。

## 漂相边界

漂相由同一活动步计算，有界整数毫米输出：稳定阶段从 40 毫米归位；平稳等待/接近为很小的三角波；试探叠加上下和侧向轻动；有效鱼口逐步下沉；中鱼后停在交接状态。纵向偏移绝对值不超过 160 毫米，横向不超过 30 毫米。

这些曲线用于接通可读漂相，不是已完成的真实浮力、风浪、渲染插值或钓竿动作。轻微水面扰动和试探都不自动打开提竿资格。绘制频率、读取快照和页面数量不消耗随机数或推进鱼口。

## 已执行的验证与限制

`test-bite.ps1` 在私有输出目录用系统 C# 编译器、警告视为错误编译独立测试。当前 29 项通过，覆盖：活动步分割一致、余数与暂停、零率/空池、阈值保持、加权池顺序、质量边界、目标锁定、开闭边界、重复和旧身份、空提/过早/过期、环境中断、终结一次、漂相边界、配置验证、不可变候选输入和线程归属。

这是纯模型检查，不等同于鼠标操作、网页或桌面验收。尚无自然遛鱼、抄网、设备损失、河床生态、压力、首鱼辅助、保存中的完整世界检查点及跨重启鱼口续局。宿主接线与玩家投影的实际证据由其各自日志另行记录。
