# 首个平面水域飞行模型

2026-10-28。`FloatFlightSimulation` 是本项目原创的轻量模型，接在[保存确认后的出手](CAST_PREPARATION.md)之后。它没有存档写入权限；构造函数中的会话 ID 只是身份，不是已扣费或拥有鱼的证明。宿主只对新确认的一次出手创建实例，后续从统一活动时钟推进。

## 轨迹与单位

- 输入点、矩形水域、可用线长使用毫米；速度为毫米/秒，重力为毫米/秒²。它们是不可变值。活动时间为整数毫秒，单步只接受 `0..250`；零步表示暂停，不读取系统时间。
- 力度 `0..1000` 在线性配置的最低/最高初速之间取值；固定仰角及重力来自显式规则。瞄准点只定义 XZ 方向，瞄准点的 Y 不参与轨迹，不能声称不同力度都会精确落在同一瞄准距离。
- 位置直接按总活动时间计算：水平匀速，垂直 `y = y₀ + vᵧt − gt²/2`。不是逐帧积分。提前求下落时与 `waterY` 的交点；终点在矩形内或边界上才进入 `Waiting`，否则进入 `Invalid/outside-water`。过大的时间步停在精确交点，Y 等于水面高度。
- `MaximumFlightMilliseconds` 是明确的失效上限，未到水面也会以 `flight-timeout` 收束。它不是任意延迟发射。

## 可用线长

本切片把竿尖/鱼线锚点固定为发射原点，线使用量是该原点到钓组的直线距离。它没有模拟弯曲鱼线、线杯阻力、竿身弹性、断线损耗或实际绕线库存。

不能只检查落点距离：高仰角轨迹可能途中超过线长，最后又回到线长范围内。模型求径向距离平方的极值，将整个飞行区间拆成单调区间，并各用最多64次二分查找首次线接触。因此结果与输入帧率、步长拆分无关。到达线长即判为 `Invalid/line-limit`；它在与落水同时发生时优先，也包含恰好触及途中最大值的情况。浮点极值比较仅使用 `1e-12` 相对容差避免切线舍入漏判，输出使用量始终限制在非负的配置预算内。

## 身份、结束和边界

`Advance(sessionId, activeMilliseconds)` 只作用于当前会话。首次进入 `Waiting` 或 `Invalid` 返回一次 `TerminalEvent`，重复调用不重发；`End` 提前终止飞行也只发一次。落水后再结束会话会改为 `Ended`，不产生第二次终点事件。旧会话不能推进或结束新的实例。

所有输入拒绝 NaN/Infinity。坐标绝对值最多 `1e9` 毫米；线预算 `1..1e9` 毫米；初速 `1..1e6` 毫米/秒；重力 `1..1e6` 毫米/秒²；仰角 `[0,90)`；时限 `1..600000` 毫秒。起点必须高于水面，水域必须有正面积，XZ 方向不能为零。方向计算经过缩放，极小的有效方向也不会因平方下溢生成非数值。

本模型只处理单块静止水平矩形水域、固定直线方向及无阻力弹道。风、空气阻力、障碍、地形碰撞、波浪、浮漂水下平衡、提竿、鱼群与遛鱼未包含。无效轨迹不会退款、补线或授予鱼，后续收竿由已有会话事务处理；保存不确定时不得构造或推进该模型。

## 验证

`test-flight.ps1` 在仓库外新目录编译并运行纯模型检查，没有读取/写入存档，也没有启动 WebView 或原生输入。包含活动步拆分、暂停、跨过落水时刻、矩形边界、途中线长最大值、切线/同时接触、超时、重复终点、旧会话、非法数值和跨线程拒绝。具体执行结果由开发日志另行记录，模型检查不能代替实际鼠标、视觉质量和水面物理验收。
