# 单竿事务文件存储候选

2026-10-27。`FloatGameStore`把同目录纯事务核心的起始状态和已确认命令写入真实文件；这是单屏主线的数据切片，尚未接入桌面宿主、游戏页面或旧0.3.1存档。它不是诊断counter的改名，也不是完整P1存档验收。

## 写入和读取

- 显式`CreateNew(path, genesis)`使用CreateNew，先验证完整起始状态，已有路径不覆盖；`OpenExisting(path)`仅打开原路径，缺失、损坏或不支持的版本不会改为新玩家初始化。调用方决定存档位置，测试只使用仓库外私有夹具。
- 一个实例持有ReadWrite句柄、FileShare.Read写锁；同路径第二个写者不能同时打开。实例内串行执行，命令和销毁不允许在提交回调中重入；外部授权仍是未来GameOwner的责任。
- 新命令先由纯reducer形成候选，再把事件写入完整帧并执行`Flush(true)`；成功后才替换`State`并返回已确认回执。配置、鱼重、锁定售价及此前回执均通过同一事件重放得到，不让页面提供余额或出售单价。
- 已有请求回放不追加文件，返回原回执和**最新**状态，不能把旧回执中的旧余额还原到当前。满护结果虽业务失败，仍保存同一待处理鱼/会话，再返回`Committed=true / OperationSucceeded=false`。
- `Committed=false`表示本次没有新确认；普通拒绝和已知容量不足不会移除部分资产。`Written`区分新确认与历史回执，不可据业务成功字段推断是否需要保存。
- 可能已经开始写入后的任何异常，将实例标为`IsFaulted`并抛出`FloatSaveUncertainException`。此后State及Execute拒绝使用；保留原文件，关闭后核验原日志。不能从旧内存状态继续接单、退款或换ID重做。

## schema 1

文件头`FDGJ0001`，随后每帧为小端payload长度、Int64连续序号、32字节前帧散列、payload、32字节SHA-256。散列覆盖长度、序号、前散列和payload。序号0是完整显式初始profile/branch/固定钓组/资源/规则；后续每条命令必须重放成恰好一个新候选。重复命令、已拒绝命令或语义不一致的帧即使散列正确也不作为提交接受。

内部`FloatJournalCodec`采用独立标记、版本和明确类型，不做通用对象反序列化或WebView JSON路由。只支持初始状态和当前6类命令（原5类加host-only Recovery），整数和GUID有固定表示；文本UTF-8严格解码、有界长度，禁止未知类型/版本、截断、尾字节、非规范或重复集合。起始数据必须序号0，不能把任意中途状态伪装成新的初始化记录。

单payload最多64KiB、单文件最多16MiB、最多10,000笔事务，全部已确认回执保留。容量检查在写入前完成，返回`save-capacity`而不把实例标成不确定；旧回执仍可查询。这些是候选容量边界，尚无生产压缩、跨版本迁移或极限重放性能验收。

## 当前恢复边界

2026-10-28 补充：[关闭存档只读核验与备份](ARCHIVE.md)已实现。独立工具复用本文同一重放检查器，以只读且禁止并发写入的句柄捕获稳定字节；备份只新建目标，flush后逐字节/散列/重放核验，不修改来源、不自动恢复会话或激活备份。28项新检查及原21项存储/29项owner/15项生命周期回归通过。下面尚无升级、自动恢复、压缩和独立回退检测的限制继续有效。

完整帧已写入但应答丢失时，重新打开可重放该笔，再用原请求取得回执；不重复扣饵或发钱。帧内截断、错误长度/散列/链、额外垃圾及语义失配会拒绝整份打开，原字节不改、不剪掉坏尾、不选择较旧状态假装成功。

SHA-256用于损坏检查，不是签名、反作弊或账户认证。**当前没有独立高水位/检查点，无法识别文件被完整回退到某个较早合法帧边界**；也没有尾部故障修复、自动备份/回退选择、历史压缩或版本升级工具。显式只读备份不等于这些能力。不能把本候选交给用户替换个人正式存档，也不能宣称所有断电损坏均已恢复。

存储打开本身只重建已确认业务状态；[唯一GameOwner与Lifecycle](OWNER.md)在明确启动/退出入口收束未完成普通会话，保留已确认pending结果。[可选宿主接线](../game-page/README.md)已连接实际页面/正常退出与暂停资格，隐藏WebView联合验证范围单列；存储打开成功不表示可以自动继续出手动画或离线捕鱼。满护已确认鱼仍是同一pending，放流须走相应一次终结。

## 实际验证

使用本机现有.NET Framework编译器，warnings-as-errors；输出只写指定仓库外目录：

```powershell
./desktop/game-core/test-pure.ps1 -OutputDirectory <已有仓库外目录>
./desktop/game-core/test-codec.ps1 -OutputDirectory <已有仓库外目录>
./desktop/game-core/test-store.ps1 -OutputDirectory <已有仓库外目录>
```

本轮主代理独立复跑：32项纯事务、23项严格编解码、21项真实私有文件检查全部通过。文件检查覆盖抛收/落鱼/出售后关闭重开、跨重启防重、第二写者、缺失坏档不初始化、帧内截断/篡改/尾垃圾拒绝、满护持久化、整批出售失败不写、写入前及半帧/整帧/flush后的注入异常、已知容量拒绝和关闭后调用。

异常通过内部脚本钩子注入；容量测试反射设置内部字节预算，不是真实磁盘耗尽。未测试真实断电、进程强杀、磁盘坏块、网络盘、个人存档或UI/原生桌面联合。编解码纯测中的`diskJournalImplemented=false`仅指该独立测试组未运行文件层，不否定另一组文件检查。
