# 独立补给存档候选

`FloatProfileUpgrade.CreateCandidate` 为本项目的 schema 1 日志创建独立 schema 2 候选。它不导入 RF4 存档，也不导入旧网页 0.3.1 存储；不替换运行档、不激活新分支、不调用会收束未完成竿的 GameOwner。

## 路径与确认

调用者明确提供源日志、独立备份和候选三个路径，目录须已存在。整个过程保持源文件只读且拒绝其他写者/删除；备份核验后同样保持只读句柄至返回。已有文件用 Windows 卷号和文件编号比较，硬链接别名不能冒充独立备份或候选。

先核验源文件和升级规则、事务及字节容量，已知不能升级时不创建输出。新备份与新候选使用 CreateNew，不覆盖任何文件。备份必须逐字节等于冻结源；候选保留原始全部前缀，仅追加一笔有完整来源证明的升级事务。原余额、体力、饵、装备、鱼护、历史和未完成/满护会话均保留，新分支无抄网、未装备、零食品。商品策略见 [补给内核](COMMERCE_MODEL.md)。

分支、升级请求/事件和食品堆叠身份由完整源摘要、完整目录签名及各自用途确定性生成。同样参数再次调用时，只读验证已经完整完成的候选：要求前缀、来源、分支、目录、食品身份、完整命令指纹及恰好源序号加一均相符。验证不会再追加升级。已经继续游玩的候选、部分副本、不同策略或另一来源均拒绝并保留。更换食品身份但其他升级身份相同的合法日志也不能冒充同一操作。

中途失败可能留下空、部分或完整但未确认的新文件，服务不删除、不修尾、不重写、不自动启用。部分候选不能靠重试变成成功；应先独立检查，之后选择新的明确路径。已关闭候选可用 [只读工具](ARCHIVE.md) 检查，仍需未来明确的分支启用流程。

```powershell
./desktop/game-core/test-commerce.ps1 -OutputDirectory '<已有仓库外目录>'
./desktop/game-core/test-upgrade.ps1 -OutputDirectory '<已有仓库外目录>'
```

命令行显式使用原创开发目录1：蚯蚓每包5个/0.20银币、抄网24银币、面包每份0.20银币恢复20体力；饵上限10000、食品1000、单次100包。它不改原钓鱼规则或旧鱼售价。不兼容源直接拒绝，没有兜底初始资金或自动发物品。输出仅含操作确认及元数据，`activated` 始终为 false。

## 装备格式的显式映射与独立候选

`FloatEquipmentMigrationPolicy` 是schema2到装备账本的纯映射；文件入口为 `FloatEquipmentProfileUpgrade.CreateCandidate`。调用者必须明确提供原钓组定义、完整新装备目录以及竿、轮、线、钩、漂、沉子的六项对应。版本、映射和完整目录内容共同进入策略摘要；缺定义、类别不符、兼容规则缺失或新线杯容不下原线段时拒绝。

映射保留原钓组和六件装备的全部身份、钓组修订及已记录整数线长。新账本的库存/物品修订从1开始，只表示进入新表示格式；不代表获得新物品、满耐久或更高等级。旧格式没有末端装备损失事务，因此其已记录可用线长作为该段初始/剩余长度，不使用新线杯容量补满。零余额、零饵或零体力照原值保留，映射不赠送补给或商品目录。

纯映射可以检查带活动竿的旧状态，但不会收竿、退款或修改会话。文件升级只接受已经收束会话的schema2源，活动竿和满护待结算状态在创建输出前拒绝。需要先通过旧格式正常收竿、入护或放流；不能把旧会话直接拼成新会话。源为schema1时先使用上面的1→2路径，源为schema3则拒绝重复升级。

type18仅在独立候选保留原字节前缀后追加一笔。写入和重放均验证源长度、末端哈希和完整前缀摘要；原1→2来源与本次2→3来源分别保留。新装备载荷必须逐字节符合对源六件装备的映射，无法替换身份、补满线段或夹带额外装备。备件报价作为显式策略写入，但不发生购买。余额、食品、抄网、鱼护、售价及既有回执保持原值。

与1→2服务相同，源和备份保持只读锁，已有路径核对Windows文件身份，输出使用CreateNew。分支/请求/事件身份由源、完整映射策略和报价策略共同确定。重试只读确认完全相符、尚未继续游玩的候选；不同规则、残缺副本、已继续游戏的候选均拒绝且保留。没有自动激活、替换、修尾或删除。

```powershell
./desktop/game-core/prepare-equipment-upgrade.ps1 -SourcePath '<已关闭且空闲的schema2源>' -BackupPath '<独立备份文件>' -CandidatePath '<新的候选文件>' -Mapping starter-float-v1 -OutputDirectory '<已有仓库外构建目录>'
./desktop/game-core/test-equipment-migration-policy.ps1 -OutputDirectory '<已有仓库外目录>'
./desktop/game-core/test-equipment-upgrade.ps1 -OutputDirectory '<已有仓库外目录>'
./desktop/game-core/test-equipment-profile-upgrade.ps1 -OutputDirectory '<已有仓库外目录>'
```

命令行必须指定 `starter-float-v1`，只映射本项目开发用 `float-starter/worm`。它使用现有开发装备定义和四项备件报价（钩0.35、漂1.20、沉子0.25、50米线4.00银币），原有鱼线仍按实际长度保留；不根据相似名称猜测未知装备。它不接受RF4或网页0.3.1存档。
