钓鱼桌面 · Windows 离线版 0.6.0 玩家指南

开始
将 FishingDesktop-0.6.0-win-x64.zip 整包解压到一个文件夹，双击根目录的 FishingDesktop.exe。app 文件夹需要与它放在一起。需要 64 位 Windows、.NET Framework 4.6.2 或更高版本，以及 Microsoft Edge WebView2 运行时。这些运行环境已安装后，可离线游玩。

岸边与营地
在水面按住左键可以看到本竿的力度，松开就抛出。想查操作时按 F1。按 Esc 打开营地总览，从中选钓场、鱼护或商店。M 打开地图，C 打开鱼护，I 查看装备，T 打开食品店。渔具店和食品店报出价格后，先确认或取消再去另一页。按 Esc 回到岸边。

先试两个钓位
按 M 查看各钓场的两个沿岸落点。回到岸边，按 A 或 D 向左或向右走，按住 Shift 可快走。地图中的步行距离随位置更新。静水湾的芦苇口和塘坎、江湾的回流口和草滩尾、海湾的沙嘴和礁台都离各自的起点约 6 米。走到提示「已到达」后松开方向键，朝该位置前方的水面抛竿。江湾的两个钓位相距约 12 米，在离岸约 19 米处有约半米的水深差，鱼口也会随水深、时间、天气和钩饵变化。
按 O 查看钓手日志。浮漂入护经验达到 10 点后，可以学习一级「稳手提竿」。下一次浮漂出现有效鱼口时，有 4.75 秒按右键提竿。已售渔获的经验也计入学习条件。
按 F1 查看操作并选择钓场画质。省电、标准和高清的绘制上限分别为 720p / 18 帧、1080p / 30 帧和 1440p / 60 帧。游戏按窗口的实际宽高比绘制，两种窗口共用选择，重开后保留。

新鱼和面饵
黄颡鱼在江湾，许氏平鲉在海湾，两种都可以用浮漂钓。在两地较深的落点，它们的相对权重更高。使用面饵时，淡水鱼群中的鲤鱼和鲫鱼更容易问饵。面饵会影响选择，鱼口仍受当天的天气、时段和水深影响。
按 T 打开食品补给，买一份面包，点「揉制 3 份面饵」，再点「挂面饵」。按 Esc 回岸边，按住鼠标左键后松开抛竿。取消蓄力不耗饵，确认抛出才扣一份。想换回蚯蚓，在食品补给里点「挂蚯蚓」。底钓继续用蚯蚓，亮片不扣虫饵。
七种鱼的旧玩家存档在符合升级条件时会先在原目录生成 game.before-nine-species.*.fltj 备份，再开放九种鱼。升级后如需退回 0.4.0 或 0.4.1，关闭游戏并保存一份新版进度，再把升级前备份复制为 game.fltj。回退只能保留升级前的进度。

在海湾岩岸用亮片钓花鲈
1. 选择「窗口试玩」，在横向岸边窗口顶部点「开启交互」。手中和架上的竿都已结束时按 M 前往海湾；若在竿架模式，先去渔具店点「退出竿架模式」。
2. 在营地「渔具店」找到「海湾亮片路亚套装」，点「购买亮片套装」并确认支付 56 银币，再点「使用亮片路亚」。新存档有 120 银币。若要留鱼，再买一张 24 银币的抄网并装备，两件合计 80 银币。已经装备的抄网可继续共用。
3. 按 Esc 回到岸边。对准海面落点按住左键蓄力，松开抛竿。确认出手消耗 2 点体力，12 克下沉亮片可重复使用，无需挂蚯蚓。
4. 入水后重新按住左键匀收，松手让亮片停顿下沉。按住 R 向上滚动滚轮可加一档，向下滚动可减一档，共五档。观察画面上的泳层、深度、出线和余线。亮片触底后继续按住左键收回岸边。
5. 看到「鱼已攻击亮片」时，立即按一次鼠标右键提竿。中鱼后松开左键，再按住左键开始遛鱼。靠岸后点「抄鱼」或按空格，渔获入护后按 C 出售。没有中鱼时继续按住左键把亮片卷回岸边，收回确认后才能再抛。结束一竿后，在营地的亮片柜台点「换回浮漂」可恢复浮漂钓法。

用浮漂钓第一条鱼
1. 选择「窗口试玩」。在「钓鱼桌面 · 岸边」窗口顶部点「开启交互」，保持窗口横向。
2. 第一次抛竿前，按 Esc 打开营地，点「渔具店」。在抄网柜台点「获取抄网报价」，核对 24.00 银币，再点「确认购买」。回到抄网柜台点「装备」，看到「已拥有 · 已装备」后按 Esc 返回钓位。
3. 在三维钓场空闲时，A 或左方向键向左走，D 或右方向键向右走，按住 Shift 可快走。每个钓位从起点向两侧各可走 8 米。松开方向键站稳后，把鼠标移到水面，出现落点圆环时按住左键蓄力，松开抛竿。浮漂明显下沉时，按一次右键提竿。
4. 中鱼后按住左键收线，松开可停止收线。滚轮调泄力，按住 R 并滚动可调收线速度。鱼靠岸、浮起且疲劳后，「抄鱼」会出现。点它或按空格，看到「渔获已入护」即可留鱼。「收回这一竿」会结束当前一竿，适合空提后重新挂饵。
5. 按 C 打开鱼护，可按鱼种筛选、按重量或入护时间排序；勾选渔获，核对条数与总价后点「确认出售」。鱼护满时，点「放流当前鱼」结束本竿，再出售鱼护里的渔获腾出空间。

在静水湾用铅坠底钓
1. 结束当前一竿后按 M 前往静水湾。打开营地的「渔具店」，找到「单钩底钓套装」，点「购买套装」，再点「确认支付 64.00 银币」。看到「已拥有」后点「使用底钓」，确认当前钓法显示「底钓」，按 Esc 返回岸边。
2. 若要留鱼，还需另外购买并装备抄网（24.00 银币）。已装备的抄网可在浮漂和底钓两种钓法间共用。
3. 准备好蚯蚓，在静水湾底钓区对准水面按住左键蓄力，松开抛竿。等铅坠落底、钓组稳住后观察明色竿尖。「竿尖轻点」表示鱼在试饵。等到「竿尖下压」时，按一次右键提竿。中鱼后按住左键收线，等「抄鱼」出现后点按钮或按空格。
4. 在营地「渔具店」点「使用浮漂」可换回浮漂。去江湾或海湾会自动切回浮漂。从这些钓场返回静水湾，要再次底钓，点「使用底钓」即可。

在静水湾架竿
1. 开局有 120 银币。第一套单钩底竿 64，三槽竿架 16，抄网 24，三件共 104。第二、第三套底竿可按顺序各花 48 银币购买。三套底竿、一个架和一张网全部买齐共 200 银币。可以先用单竿钓鱼并出售，再添下一套。若余额低于 32 银币、鱼护为空且手上和架上的钓组都已收回，可打开营地「帮工」工作一分钟，再点「领取报酬」取得 8 银币。工作时保持营地在前台。
2. 一竿结束后，在静水湾的营地「渔具店」购买第一套底竿和三槽竿架，点「进入竿架模式」，按 Esc 回岸边。购买抄网后记得装备，三支竿可以共用。
3. 起初手中无竿，已有的底竿分别插在架上。按 1、2、3 取相应槽位的竿，或空手按 E 取最近可拿的竿。像单竿底钓一样在水面按住左键蓄力，再松开抛投。等铅坠沉底、钓组稳定，手持状态显示「等鱼」后按 X 放回最近的空位。再取另一竿重复操作。手中有可放的竿，且架上有可及空位时，按其他有竿的槽号可直接换竿。
4. 看架上哪一槽出现「竿尖下压」，按对应数字取竿，趁鱼口仍在按右键提竿。手持中鱼的竿遛鱼，靠岸后点击「抄鱼」或按空格。错过鱼口时取回对应的竿，点「收回这一竿」后重新抛投。
5. 卖鱼前依次处理或收回每一支仍在水中的竿，再按 C 勾选出售。鱼护满时，先明确「放流当前鱼」。要购买下一套底竿或换钓场，在每一竿结束后到营地「渔具店」点「退出竿架模式」，然后添竿或按 M 选钓场。重新进入竿架模式时，已购底竿会再次放在架上。

换钓场与补给
按 O 可打开钓手日志，查看每种钓法的抛竿、入护和经验，以及各鱼种的个人最大重量和累计售鱼收入。卖出的鱼仍计入个人纪录，重开后可在日志里继续查看。按 Esc 返回营地。
近看渔获：按 C 进入鱼护，在自己钓起的鱼旁点击「查看鱼体」。拖动旋转、滚轮缩放；也可以用方向键和加减键。按 Esc 返回鱼护。查看不会选中要卖的鱼，也不会改变它的重量、价格或存档。
进入钓场时是早上 07:30，约 24 分钟有效游玩时间经历一天。岸边显示当前时刻、云雨、温度和风速。换图时仍是同一时刻，各地天气可以不同。鱼种受当地时刻、降雨和实际钓点水深影响；鱼已经追饵后不会因天气变化换一条。营地菜单与游戏暂停期间时间不走。关窗退出再开从早上开始，装备和渔获仍读原存档。
一竿结束后按 M，查看静水湾、江湾或海湾的鱼种，点「前往钓点」，再按 Esc 回到岸边。按 I 查看钓组，按 T 买面包或食用已有食品。营地的「服装商店」可以购买及换穿钓鱼服。
缺钱补给时，先卖出鱼护中的鱼。如果鱼护已空、各竿都已收回、余额低于 32 银币，可在营地选择帮工。保持窗口和菜单开启一分钟，然后点「领取报酬」得 8 银币，用来买饵或食物。

桌面壁纸
在启动器选择「设为桌面」，钓场将显示在桌面图标后方。要钓鱼，双击任务栏通知区域的钓鱼桌面图标，或右键图标选「打开交互窗」，再点「开启交互」。关掉岸边窗口后，壁纸会继续运行。要结束壁纸或切换模式，请在托盘右键选「退出钓鱼桌面」，再打开启动器。

恢复操作与画面
打开营地或切换到其他程序时会停步。切回岸边窗口后点「开启交互」，重新按方向键走位或按鼠标钓鱼。看到「请横屏游玩」时，将窗口拉宽至宽度大于高度，然后重新开启交互。
三维画面无法显示时，游戏会切到俯视图。在图内按住左键选择落点，松开即可抛竿。如果桌面层不可用，退出后选择「窗口试玩」，可继续使用同一份进度。如果启动时提示缺少 WebView2，请安装微软提供的 Evergreen WebView2 Runtime（x64），再重新启动。

存档
窗口试玩与桌面壁纸共用当前 Windows 用户的进度。可将以下路径粘贴到文件资源管理器的地址栏。
%LOCALAPPDATA%\FishingDesktop\Preview
0.6.0 使用已有 Windows 试玩存档的位置。当前单个存档可容纳最多 10,000 笔游戏记录和 16 MB 数据。接近上限时，先结束当前一竿、退出，再备份 game.fltj。要另开一档，关闭游戏，把 game.fltj 移到单独的备份文件夹，再启动游戏建立新档。要换回来，关闭游戏，先另存新档，再把旧档放回以上目录。
更新前先退出旧版（使用壁纸时从托盘选「退出钓鱼桌面」），把 game.fltj 复制到另一个文件夹备份，再把新版 ZIP 解压到独立文件夹后启动。0.6.0 可以接续已有的 Windows 试玩进度。学习「稳手提竿」会写入新版技能记录；想回到 0.5.0 时请使用更新前的备份。
降级时先退出游戏，另存当前新版进度，再把升级前备份的 game.fltj 放回以上目录，随后打开旧版。请在旧版中使用对应版本的备份。

随包材质
静水湾岸土、江湾卵石和海湾礁石使用 Poly Haven 的 Forest Ground 04、Floor Pebbles 01 和 Rock 01 三款 CC0 材质。三张贴图位于 app\page\scene-assets，游戏从本地读取。作者、原图链接和许可说明在 app\SCENE-ASSET-CREDITS.txt 中。
