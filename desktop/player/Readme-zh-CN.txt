钓鱼桌面 · Windows 试玩指南

开始
将整个 Windows 试玩 ZIP 解压到一个文件夹，双击根目录的 FishingDesktop.exe。app 文件夹需要与它放在一起。需要 64 位 Windows、.NET Framework 4.6.2 或更高版本，以及 Microsoft Edge WebView2 运行时。

第一条鱼
1. 选择「窗口试玩」。在「钓鱼桌面 · 岸边」窗口顶部点「开启交互」，保持窗口横向。
2. 第一次抛竿前，按 Esc 打开营地，点「渔具店」。在抄网柜台点「获取抄网报价」，核对 24.00 银币，再点「确认购买」。回到抄网柜台点「装备」，看到「已拥有 · 已装备」后按 Esc 返回钓位。
3. 把鼠标移到水面，出现落点圆环时按住左键蓄力，松开抛竿。等浮漂明显下沉，按一次右键提竿。
4. 中鱼后按住左键收线，松开可停止收线。滚轮调泄力，按住 R 并滚动可调收线速度。鱼靠岸、浮起且疲劳后，「抄鱼」会出现。点它或按空格，看到「渔获已入护」即可留鱼。「收回这一竿」会结束当前一竿，适合空提后重新挂饵。
5. 按 C 打开鱼护，勾选要出售的鱼，再点「出售选中的鱼」。鱼护满时，当前鱼会显示为待处理；点「放流当前鱼」结束本竿，再出售鱼护里的渔获腾出空间。

换钓场与补给
一竿结束后按 M，查看静水湾、江湾或海湾的鱼种，点「前往钓点」，再按 Esc 回到岸边。按 I 查看钓组，按 T 买面包或食用已有食品。营地的「服装商店」可以购买及换穿钓鱼服。

桌面壁纸
在启动器选择「设为桌面」，钓场将显示在桌面图标后方。要钓鱼，双击任务栏通知区域的钓鱼桌面图标，或右键图标选「打开交互窗」，再点「开启交互」。关掉岸边窗口后，壁纸会继续运行。要结束壁纸或切换模式，请在托盘右键选「退出钓鱼桌面」，再打开启动器。

恢复操作与画面
切换到其他程序会结束当前鼠标操作。切回岸边窗口后点「开启交互」，再重新按下鼠标。看到「请横屏游玩」时，将窗口拉宽至宽度大于高度，然后重新开启交互。
三维画面无法显示时，游戏会切到俯视图。在图内按住左键选择落点，松开即可抛竿。如果桌面层不可用，退出后选择「窗口试玩」，可继续使用同一份进度。如果启动时提示缺少 WebView2，请安装微软提供的 Evergreen WebView2 Runtime（x64），再重新启动。

存档
窗口试玩与桌面壁纸共用当前 Windows 用户的进度。可将以下路径粘贴到文件资源管理器的地址栏。
%LOCALAPPDATA%\FishingDesktop\Preview
退出钓鱼桌面后，复制其中的 game.fltj 即可备份。更新时把新版 ZIP 解压到独立文件夹，再从新版启动器进入。
