钓鱼桌面 · Windows 试玩指南 0.4.0-preview.4

开始
将 FishingDesktop-0.4.0-preview.4-win-x64.zip 整包解压到一个文件夹，双击根目录的 FishingDesktop.exe。app 文件夹需要与它放在一起。需要 64 位 Windows、.NET Framework 4.6.2 或更高版本，以及 Microsoft Edge WebView2 运行时。这些运行环境已安装后，可离线游玩。

用浮漂钓第一条鱼
1. 选择「窗口试玩」。在「钓鱼桌面 · 岸边」窗口顶部点「开启交互」，保持窗口横向。
2. 第一次抛竿前，按 Esc 打开营地，点「渔具店」。在抄网柜台点「获取抄网报价」，核对 24.00 银币，再点「确认购买」。回到抄网柜台点「装备」，看到「已拥有 · 已装备」后按 Esc 返回钓位。
3. 在三维钓场空闲时，A 或左方向键向左走，D 或右方向键向右走，按住 Shift 可快走。每个钓位从起点向两侧各可走 8 米。松开方向键站稳后，把鼠标移到水面，出现落点圆环时按住左键蓄力，松开抛竿。浮漂明显下沉时，按一次右键提竿。
4. 中鱼后按住左键收线，松开可停止收线。滚轮调泄力，按住 R 并滚动可调收线速度。鱼靠岸、浮起且疲劳后，「抄鱼」会出现。点它或按空格，看到「渔获已入护」即可留鱼。「收回这一竿」会结束当前一竿，适合空提后重新挂饵。
5. 按 C 打开鱼护，勾选要出售的鱼，再点「出售选中的鱼」。鱼护满时，点「放流当前鱼」结束本竿，再出售鱼护里的渔获腾出空间。

在静水湾用铅坠底钓
1. 结束当前一竿后按 M 前往静水湾。打开营地的「渔具店」，找到「单钩底钓套装」，点「购买套装」，再点「确认支付 64.00 银币」。看到「已拥有」后点「使用底钓」，确认当前钓法显示「底钓」，按 Esc 返回岸边。
2. 若要留鱼，还需另外购买并装备抄网（24.00 银币）。已装备的抄网可在浮漂和底钓两种钓法间共用。
3. 准备好蚯蚓，在静水湾底钓区对准水面按住左键蓄力，松开抛竿。等铅坠落底、钓组稳住后观察明色竿尖。「竿尖轻点」表示鱼在试饵。等到「竿尖下压」时，按一次右键提竿。中鱼后按住左键收线，等「抄鱼」出现后点按钮或按空格。
4. 在营地「渔具店」点「使用浮漂」可换回浮漂。去江湾或海湾会自动切回浮漂。从这些钓场返回静水湾，要再次底钓，点「使用底钓」即可。

在静水湾架竿
1. 开局有 120 银币。第一套单钩底竿 64，三槽竿架 16，抄网 24，三件共 104。第二、第三套底竿可按顺序各花 48 银币购买。三套底竿、一个架和一张网全部买齐共 200 银币。可以先用单竿钓鱼并出售，再添下一套。若余额低于 32 银币、鱼护为空且手上和架上的钓组都已收回，可打开营地「帮工」工作一分钟，再点「领取报酬」取得 8 银币。工作时保持营地在前台。
2. 一竿结束后，在静水湾的营地「渔具店」购买第一套底竿和三槽竿架，点「进入竿架模式」，按 Esc 回岸边。购买抄网后记得装备，三支竿可以共用。
3. 起初手中无竿，已有的底竿分别插在架上。按 1、2、3 取相应槽位的竿，或空手按 E 取最近可拿的竿。像单竿底钓一样在水面按住左键蓄力，再松开抛投。等铅坠沉底、钓组稳定，手持状态显示「等鱼」后按 X 放回最近的空位。再取另一竿重复操作。手中有可放的竿，且架上有可及空位时，按其他有竿的槽号可直接换竿。
4. 看架上哪一槽出现「竿尖下压」，按对应数字取竿，趁鱼口仍在按右键提竿。手持中鱼的竿遛鱼，靠岸后点击「抄鱼」或按空格。错过鱼口时取回对应的竿，点「收回这一竿」后重新抛投。
5. 卖鱼前依次处理或收回每一支仍在水中的竿，再按 C 勾选出售。鱼护满时，先明确「放流当前鱼」。要购买下一套底竿或换钓场，在每一竿结束后到营地「渔具店」点「退出竿架模式」，然后添竿或按 M 选钓场。重新进入竿架模式时，已购底竿会再次放在架上。

换钓场与补给
一竿结束后按 M，查看静水湾、江湾或海湾的鱼种，点「前往钓点」，再按 Esc 回到岸边。按 I 查看钓组，按 T 买面包或食用已有食品。营地的「服装商店」可以购买及换穿钓鱼服。

桌面壁纸
在启动器选择「设为桌面」，钓场将显示在桌面图标后方。要钓鱼，双击任务栏通知区域的钓鱼桌面图标，或右键图标选「打开交互窗」，再点「开启交互」。关掉岸边窗口后，壁纸会继续运行。要结束壁纸或切换模式，请在托盘右键选「退出钓鱼桌面」，再打开启动器。

恢复操作与画面
打开营地或切换到其他程序时会停步。切回岸边窗口后点「开启交互」，重新按方向键走位或按鼠标钓鱼。看到「请横屏游玩」时，将窗口拉宽至宽度大于高度，然后重新开启交互。
三维画面无法显示时，游戏会切到俯视图。在图内按住左键选择落点，松开即可抛竿。如果桌面层不可用，退出后选择「窗口试玩」，可继续使用同一份进度。如果启动时提示缺少 WebView2，请安装微软提供的 Evergreen WebView2 Runtime（x64），再重新启动。

存档
窗口试玩与桌面壁纸共用当前 Windows 用户的进度。可将以下路径粘贴到文件资源管理器的地址栏。
%LOCALAPPDATA%\FishingDesktop\Preview
更新前先退出旧版（使用壁纸时从托盘选「退出钓鱼桌面」），把 game.fltj 复制到另一个文件夹备份，将新版 ZIP 解压到独立文件夹后启动。窗口与壁纸共用这份存档。新版可读取上一版正常退出的试玩档。买竿架、添备用底竿和用竿架抛投都会写入新版记录。
降级时先退出游戏，另存当前新版进度，再把更新前备份的 game.fltj 放回以上目录，随后打开旧版。含新版三竿记录的进度无法由旧版读取。

随包材质
静水湾岸土、江湾卵石和海湾礁石使用 Poly Haven 的 Forest Ground 04、Floor Pebbles 01 和 Rock 01 三款 CC0 材质。三张贴图位于 app\page\scene-assets，游戏从本地读取。作者、原图链接和许可说明在 app\SCENE-ASSET-CREDITS.txt 中。
