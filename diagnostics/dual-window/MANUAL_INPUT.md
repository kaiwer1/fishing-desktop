# 有时限的桌面集成输入候选

只读页挂到已核对的现有桌面层，交互页是独立普通窗口，共用原诊断的一个 owner 和计数日志。没有游戏、RF4素材、正式存档或新的桌面层创建路径。没有现有层时拒绝运行；不自动启动 Lively 或改变壁纸配置。

```powershell
./diagnostics/dual-window/run-manual.ps1 -SdkDirectory <SDK目录> -OutputDirectory <已有仓库外目录> -Seconds 300
# 隐藏并禁用交互窗，只测现有层呈现、页面加载与到时退出。
./diagnostics/dual-window/run-manual.ps1 -SdkDirectory <SDK目录> -OutputDirectory <已有仓库外目录> -Seconds 60 -UnattendedTimeoutCheck
node diagnostics/input-window/summarize-manual.mjs <本轮目录> --operator-confirmed
./diagnostics/dual-window/test-manual-record.ps1 -OutputDirectory <已有仓库外目录>
```

时限60至600秒。启动不抢焦点、不注入事件或注册全局热键；无人模式隐藏且不可激活交互窗，不显示托盘。人工模式需点进窗口，点击“开启交互”，在绿色区域按下并松开左/右/中键、滚动滚轮、按普通字母键。最后在该区域按住左键，Alt+Tab 切到别处，松开后返回，保持交互关闭。原生失焦原因独立传到输入记录，不能用普通撤销伪装成按住切窗。

六项清单仅表示本页记录；离线还需核对宿主当时的前台、运行策略与已发放授权，正常退出和明确人工确认。宿主条件不满足时，按下/松开/滚轮/键盘记录降为非可信候选，不能补齐操作验收。记录和命令分开处理；记录不会提交计数。任意按键内容、坐标、未知字段与任意原因文本不写入记录，只允许固定模式和计数。原始事件、日志、profile、自有页面图片都留在仓库外。

窗口关闭与应用退出沿用原规则：仅关闭交互窗不释放 owner，可从托盘重开，时限仍生效；“退出本轮测试”或本轮私有退出请求关闭整个诊断。时限、失效与清理均不恢复旧输入授权。原生环境采样、会话/电源接收、显示变化屏障、只读页挂起继续启用；本轮呈现是静态共享计数页，不作三维性能测试。

图标选中、系统右键菜单、拖动、最终桌面合成、多屏需分别取得操作者或可用原生工具的证据；六项变绿不能代替这些检查。当前仍不接受 P0 整体验收。
