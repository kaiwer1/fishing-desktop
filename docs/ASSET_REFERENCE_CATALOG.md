# 全量资产参考图制作清单 v1

2026-10-27，北京时间。用户要求查看聊天室，列出项目需要的全部鱼类与模型，交给 ZCode 准备参考图。本清单覆盖当前可预见的单竿、底钓、路亚、菜单商店、写实钓位及后期海钓资产；是制作规划，不是所有功能已实现或全部模型立即生成的承诺。

## 交接与现状

- **规划 36 种鱼：20 种内陆淡水鱼、16 种海水/河口鱼；另有 100 项非鱼资产参考任务。** 后者包含套件及仅需菜单图片的物品，不等于立即生成100个3D模型。
- 原首批18种保留，不推倒重做。ZCode在聊天室报告18张Gemini标准图完成；本项目已读取清单并确认18个PNG文件存在，尚未逐张复验形态或验收3D。
- 本次新增18种是Codex按中国内陆与海洋范围作的内容规划，不是用户逐种点名；每种先一个成年基础形态，不为大小、稀有度、售价或换色另生成物种。
- 当前授权是参考图准备，沿用用户已有且无需额外付费的出图方式。**不自动启动Tripo，不充值、不消耗新增付费API积分，不把参考图交接当成3D付费批准。** 之前的两件模型120积分提案仍未批准。
- 暂定制作顺序：已有18鱼查漏 → A类非鱼19项 → 新增淡水8种与B类37项 → 新增海水10种与C类32项 → D类12项。每条先主图；必要辅助角度随后补，不一次强制铺开全部视角。
- 主清单与[原建模规格](ASSET_MODEL_BRIEF.md)配合使用；数量和资产范围以本文件较新版本为准，GLB、尺度、LOD与动作要求仍沿用原规格。全部名称/ID用于美术交接，尚未写入旧存档物种ID。

## 参考图统一要求

### 鱼

先交一张物种主图：单条、完整侧面、身体平直、活体自然姿态、背景白色、柔和均匀光照、无水面/抄网/手/冰块/文字/比例尺。常规鱼默认头朝左；鳍自然展开到能辨认结构，不强迫所有鳍完全打开成扇面。保留真实须、鳍、口裂和鳞片，不把生成图本身当作生物事实。

主图建议长边至少1600像素，保留边缘余量，鱼体约占画面75%–85%。不要把多条鱼、多个视图或多种物种拼在同一张图生3D主输入里。补充视图分别命名，保持同一物种、个体比例和体色：背部/腹部、头部嘴须、主要鳍和尾部。普通侧面对隐藏结构不作猜补。

**褐牙鲆例外**：单独准备有眼面和无眼面、头部侧向关系参考；不能镜像侧面去“制造”另一面，也不要套普通圆身鱼的对称模板。带鱼保留真实尾端结构，禁止补一副普通鱼尾。两类特殊体形先核参考再出图。

同种的幼鱼、繁殖色、雌雄差异、白化/锦鲤等特殊形态暂不批量制作。以后确有玩法需求再另立variant，不靠同一模型随意缩放覆盖所有生活阶段。

### 竿轮、手部和配件

- 竿、轮、鱼线、手必须独立；竿全长图与握把/轮座/导环细节图分开。细长竿不强求单张图生3D一次得到可用结构，后续允许手工/程序化建模。
- 渔轮保留真实旋转机构；参考中不让摇臂、线杯和线规互相粘连。右手持竿/左手摇轮为首个动作样本方向，但左右手、轮柄的模型结构应能分别处理。
- 手部用同一比例基准分别出左右手及前臂，掌面、背面和握持检查图分开；不要因为透视把手指缩掉或合并。衣袖以统一腕部接口适配。
- 配件采用单物体主图。小件虽放大展示，清单须保留真实尺寸记录；不能把图片大小当世界尺寸。图片参考尺寸不等于最终装备数值配表。

### 服装、食品与场景

服装正背侧使用同一无脸人体台，食品做单品菜单图。用户买卖走菜单，**不需要渔具店、食品店、服装店和鱼市建筑模型，也不需要店员NPC**。完整可操作人物尚未确定，当前先做手/前臂/袖口；服装图不等于已授权扩充完整角色系统。

场景对象单独制作，岸石、草、芦苇和树用少量基础形体做实例变体。风景概念图另存，不能拿整张风景当一个可行走钓场模型。场景中可走地形、水深与障碍仍由开发侧统一构建。

## 不作为独立3D模型生成的内容

| 内容 | 处理方向 |
| --- | --- |
| 鱼线、前导线、线杯缠线的动态表现 | 运行时曲线/程序化几何，模型只留挂点 |
| 水面、波纹、反射、折射、浪花与雨雪 | 材质、着色器和粒子；可准备材质参考，不能用静态水块代替 |
| 天空、雾、昼夜与远景层 | 天空/环境贴图与光照；参考图和授权另登记 |
| 泥土、沙、岩石、木材、草地纹理 | 可平铺材质；不把照片自动视为已生成准确PBR贴图 |
| UI图标、商店卡片、鱼种图鉴缩略图 | 从合格参考或模型统一出图，界面图标独立绘制 |
| 食物和仅在菜单展示的衣物 | 优先2D；需要手持/穿戴近景时才做相应3D部分 |
| 飞鸟、昆虫及装饰动物 | 暂不在本版必需模型范围，避免抢占核心钓位制作 |
