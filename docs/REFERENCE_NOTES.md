# 玩法与画面参考记录

## 2026-10-19

参考来自用户提供的《俄罗斯钓鱼4》截图与本机录屏。录屏约 10 分钟，以抽样关键帧方式查看，未逐帧完整审阅；抽样中未见完整提竿与遛鱼流程，因此不据此推断这些动作的精确时长。

### 观察

- 水边以第一人称为主，远处树林、湖面倒影和天气构成主体，状态信息分布在边缘。
- 三支底钓竿放置在支架上，守钓与查看菜单可以交替进行。
- 背包采用分类与物品卡片，渔具的长度、承重和用途需要清晰可查。
- 地图选择有环境预览、鱼种描述、天气与进入条件。
- 步行经过营地建筑后进入商店，鱼饵、渔具、鱼市和维修形成补给流程。
- 鱼市可以选择渔获并显示售价；图鉴、个人纪录与技能支撑长期目标。

### 本项目应用

0.2 先验证单竿钓鱼、卖鱼、补给和装备成长，采用固定钓位与菜单进行交易。地图、鱼饵适用性及鱼类纪录已经接入。守钓多竿、钓点探索、维修、制作和技能树仍待实现。

用户随后明确：买卖和补给采用菜单，地图移动只用于找钓点。参考中的步行前往商店、鱼市建筑不作为本项目要求，也不列入后续开发范围。

视觉方向保留自然环境主体、边缘信息和按需打开菜单。当前几何树木、鱼竿与鱼类示意图仅用于玩法验证，不能代表目标写实效果。
