# P0：桌面宿主基线

2026-10-19。当前先验证已发布样机的宿主路线，不扩展钓鱼流程或界面。通过构建不代表通过桌面验收。

## 基线身份

- 源码版本：公开提交 `e2e3988`，玩法仍为 0.3.1。
- 从 Git 已提交内容导出独立目录，复用锁定版本的已安装依赖；没有将原工作目录未提交的界面草稿带入构建。
- 已执行原有 19 项测试，全部通过；Vite 正式构建完成。约 600.68 kB 的主 JS 包触发体积提示，暂未做拆包优化，不能据此推算运行帧率。
- 候选 Lively ZIP：176,846 字节，SHA-256 `599deb38b4ba58d85b8a128e20daa0046dfea27133c7deb040b572c1f5e48c34`。这是本次生成包的身份，不保证跨时区/打包时间字节完全复现。

## 宿主准备

官方 Lively 2.2.1.0 安装包已核对先前记录的 SHA-256。安装器报告未带 Authenticode 签名，不称作已验证数字签名。已读取对应版本官方安装脚本，核对安装依赖、禁止自动启动选项和开机任务选项；已安装到仓库外的项目工具目录。

安装器退出码 0，主程序版本 2.2.1.0，日志显示不需要重启。实际宿主为 x64/.NET 9，已启动宿主与 WebView2 播放器；不根据安装包文件名将它误记为 x86 宿主。

## 2026-10-19 16:15 实际宿主试验

- 初始没有 Lively 壁纸，先保存新宿主的设置和空布局。没有改写 Windows 原有静态壁纸设置。
- 直接将外部目录交给 CLI 未加载；核对官方命令处理源码后发现，该版本只接受位于宿主壁纸库内的项目目录。把本项目基线复制到新建的专用库目录后再次加载。
- 宿主日志记录主屏 1920×1080 的 WorkerW 桌面层设置、WebView2 播放器创建和本地页面导航成功。该成功事件只确认导航，不确认三维画面、完整脚本初始化或交互正常。
- 使用宿主官方壁纸截图命令尝试两次，分别输出到项目记录目录及宿主自身目录；两次均在约 5 秒后超时，没有生成图片。尚不能认定原因是目录权限、网页错误、截图接口或当前显示环境；没有使用其他应用的屏幕内容替代验收。
- 结束试验后，通过官方命令关闭测试壁纸和宿主，布局恢复为空，宿主与测试播放器已退出。通过官方选项关闭此次测试安装的开机启动。
- 未做帧率、GPU/显存、长期内存和自动暂停验收。单次进程存在或导航成功不能代替这些检查。下一项为最小诊断页面与播放器日志核对，先区分页面执行/绘制和截图接口问题，再测暂停与输入。

## 2026-10-19 18:35 诊断与暂停对照

新增[独立诊断工具](../diagnostics/lively-host/README.md)，使用本机回环收集器记录 Canvas/WebGL 像素读回、计数与宿主回调，不读取账户、存档或其他应用画面。游戏源码及暂停中的界面草稿未修改。

1. Lively 实际加载本地诊断页到 1920×1080 桌面层。Canvas 2D 与 WebGL 像素检查均通过，WebGL 错误码为 0；属性 `probe=7` 和 `IsPaused=true/false` 回调均到达。已取得并查看[诊断壁纸截图](validation/2026-10-19-probe.jpg)。
2. 播放时，官方壁纸截图成功。手动暂停后请求截图，宿主约 5 秒超时；恢复播放后，同一请求迟到完成并生成图片。随后新的播放态截图也成功。该版本官方源码的 `Pause()` 会对图形子进程调用 `DebugActiveProcess`，而截图依赖 `Page.captureScreenshot`。这解释了本次对照中暂停与截图超时的关联；上一轮没有记录当时暂停状态，不能倒推两次旧失败的唯一原因。
3. 对**未插入诊断代码**的 `e2e3988` 干净 0.3.1 基线，已取得并查看[游戏壁纸截图](validation/2026-10-19-baseline.jpg)，确认三维场景与 HUD 实际绘制。场景仍为几何占位美术，不表示达到写实要求；截图也不证明桌面图标与鼠标正常。
4. 将同一基线复制到另一个专用目录，仅在导出 HTML 加入观察器；原游戏模块未改。手动暂停持续 13.995 秒，14 个暂停心跳样本的 draw 调用数都为 15,525，环境时钟均为 06:35。恢复回调时仍为 06:35，首个恢复心跳开始重新绘制，之后环境时钟持续推进。观察器未收到页面错误事件。这只验证“准备抛竿”状态的短时手动暂停及恢复，不证明所有玩法状态、全屏策略或锁屏行为。
5. 测试后关闭壁纸、宿主和回环收集器；布局恢复为空，宿主/播放器进程数为 0，开机启动注册项不存在。没有修改宿主暂停策略设置，没有设置全局热键或锁定鼠标。原始日志与会话记录留在仓库外；公开的是工具、整理结论和仅含本项目画面的截图。

`Start-Process -Wait` 等待 CLI 子进程，不保证宿主异步操作已经完成。本轮按文件与宿主日志核对最终结果；迟到的暂停截图未计为暂停态成功。
